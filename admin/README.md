# Aurelia Dental — Admin

React + Vite admin panel for clinic operations (appointments, CMS, staff, payments).

## Local development

From the monorepo root:

```bash
npm run dev:admin
```

Defaults to `http://localhost:5173` and talks to the API at `VITE_API_URL` (see `.env.example`).

Full platform setup, env vars, and deployment notes live in the root [README](../README.md).
